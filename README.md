# weather_etl

Данное приложение реализует ETL[^1]-пайплайн для автоматизации загрузки, обработки и выгрузки почасовых и ежедневных прогнозов погоды из API Open-Meteo. Результирующие данные сохраняются в формате CSV, а в расширенной версии поддерживается выгрузка в реляционные базы данных.

[^1]:ETL (Extract, Transform, Load) — процесс извлечения данных из разных источников, преобразования их в нужный формат и загрузки в целевое хранилище.

## Установка зависимостей

bash

``pip install -r requirements.txt``

Запуск с помощью Docker

bash

``docker-compose up --build``


## Входные данные

| Поле                  | Описание                                | Пример           |
|-----------------------|-----------------------------------------|------------------|
| latitude              | Широта запрашиваемого местоположения    | 55.0             |
| longitude             | Долгота запрашиваемого местоположения   | 83.0             |
| generationtime_ms     | Время генерации ответа API (мс)         | 0.26             |
| utc_offset_seconds    | Смещение времени относительно UTC (сек) | 25200 (GMT+7)    |
| timezone              | Часовой пояс                            | Asia/Novosibirsk |
| timezone_abbreviation | Аббревиатура часового пояса             | GMT+7            |
| elevation             | Высота над уровнем моря (метры)         | 135.0            |
